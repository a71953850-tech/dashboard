국방예산 인사이트 대시보드

실행: dashboard 폴더의 index.html을 Chrome 또는 Edge에서 여세요.
설치, 인터넷 연결, 서버 실행 없이 작동합니다.

기능
- 부문 / 회계구분 필터, 프로그램·구분 검색, 필터 초기화
- 2026년 / 2027년 구성 기준 전환
- 4개 요약 지표와 9종의 반응형 시각화
- 마우스 오버 상세 정보, 상세 표 정렬, 선택 데이터 CSV 저장
- 모바일 및 인쇄 레이아웃

데이터 기준
- 원본: 상위 폴더의 프로그램별_재원_2026_2027.xlsx
- 총 32개 항목. 금액 단위는 억 원이며 2027년은 정부안입니다.
- 증감 = 2027년 - 2026년, 증감률 = 증감 / 2026년.
- 내부거래 차감 항목은 음수로 합산합니다.
- 도넛 / 예산 지도 / 예산 순위 / 성장률 분포는 양수 항목 기준입니다.
- 성장률 분포의 가로축은 넓은 예산 범위를 비교하기 위한 로그 눈금입니다.
- 음수 기준 증감률은 차감액 크기 변화이며 금액 증감 부호와 다를 수 있습니다.
- 합계는 엑셀의 항목을 합산합니다. 원문 총재원과 1억 원 차이가 있습니다.
- 부문/회계/검색 조건은 모든 차트, 지표, 표, CSV에 적용됩니다.
- 연도 버튼은 구성 도넛, 예산 지도, 규모 TOP 10에 적용됩니다.

엑셀 수정 후 데이터 갱신
이 대시보드는 제작 시점의 데이터를 포함합니다. 자동으로 원본을 읽지 않습니다.
Python과 openpyxl이 있는 환경에서 dashboard 폴더의 update_data.py를 실행하면
동일한 원본의 7~38행을 다시 읽어 data.js를 갱신합니다. 이후 브라우저를 새로고침하세요.

파일 구성
index.html: 시작 페이지
styles.css: 디자인, 모바일 및 인쇄 스타일
app.js: 인터랙션 및 SVG 그래프
core.js: 필터·합계·그룹 계산
data.js: 엑셀에서 추출한 데이터
update_data.py: 원본 엑셀 데이터 갱신 도구
